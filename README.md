# Pixel Art Quiz Game (教師資格檢定版)

這是一個基於 React + Vite 開發的像素風格闖關問答遊戲。遊戲題目與成績系統皆透過 Google Sheets 與 Google Apps Script (GAS) 進行管理。

## 🎮 功能特色
- **像素風格 UI**：復古街機設計感，包含 CRT 掃描線與霓虹特效。
- **動態關卡**：每一關隨機生成不同的像素關主 (使用 DiceBear API)。
- **Google Sheets 整合**：後台直接在試算表編輯題目、查看即時成績。
- **手機適配**：響應式設計，支援手機與平板遊玩。

---

## 🚀 快速安裝與執行

### 1. 下載專案與安裝依賴
確保電腦已安裝 [Node.js](https://nodejs.org/) (建議 v16 以上)。

```bash
# 1. 進入專案目錄
cd pixel_game

# 2. 安裝必要套件
npm install

# 3. 啟動開發伺服器
npm run dev
```
啟動後，瀏覽器打開顯示的網址（通常是 `http://localhost:5173`）。

> **注意**：首次啟動若未設定 `.env`，遊戲會使用內建的模擬數據運作。

## ☁️ Google Sheets 與 後端設定

此專案核心依賴 Google Sheets 作為資料庫，請務必完成以下設定。

### 第一步：建立 Google Sheet
1. 前往 Google Sheets 新增一個空白試算表。
2. 建立兩個工作表（Tab），名稱必須完全一致：
   - `題目`
   - `回答`

### 第二步：設定工作表欄位

請將以下欄位名稱複製並填入各工作表的 **第一列 (Row 1)**：

**工作表：`題目`**
| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| 題號 | 題目 | A | B | C | D | 解答 | 科目 |

**工作表：`回答`**
| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| ID | 闖關次數 | 總分 | 最高分 | 第一次通關分數 | 花了幾次通關 | 最近遊玩時間 |

---

### 第三步：部署 Google Apps Script
1. 在該 Google Sheet 中，點選上方選單的 **「擴充功能」 (Extensions)** -> **「Apps Script」**。
2. 將專案資料夾中的 `google_apps_script_source.js` 檔案內容 **完整複製**。
3. 清空 Apps Script 編輯器中的預設程式碼，並 **貼上** 剛剛複製的內容。
4. 按下磁碟片圖示存檔。
5. 點選右上角的 **「部署」 (Deploy)** -> **「新增部署作業」 (New deployment)**。
6. 點選左側齒輪 -> **「網頁應用程式」 (Web app)**。
7. 設定如下：
   - **說明**：Pixel Game API (或任意名稱)
   - **執行身分**：**我 (Me)**
   - **存取權限**：**所有人 (Anyone)**  <-- ⚠️ 極重要！選錯會導致前端無法存取。
8. 點選 **「部署」**。
9. 複製回傳的 **網頁應用程式網址 (Web App URL)** (以 `exec` 結尾)。

---

### 第四步：連線設定 (.env)
1. 回到專案目錄，打開 `.env` 檔案。
2. 將刚刚複製的網址填入 `VITE_GOOGLE_APP_SCRIPT_URL`。
3. 您也可以在此調整通過門檻與題目數量：

```env
VITE_GOOGLE_APP_SCRIPT_URL=https://script.google.com/macros/s/您的部署ID/exec
VITE_PASS_THRESHOLD=3
VITE_QUESTION_COUNT=5
```
4. **重啟前端伺服器**：若伺服器正在執行，請按 `Ctrl+C` 停止並重新執行 `npm run dev` 讓設定生效。

## 🚀 部署到 GitHub Pages

本專案已設定好 GitHub Actions 自動化部署流程，請依照以下步驟操作：

### 1. 設定 Repository Secrets

為了安全起見，API 網址不會上傳到 GitHub，您需要在專案的 Settings 中設定 Secrets：

1. 進入您的 GitHub Repository 頁面。
2. 點擊 **Settings** -> **Secrets and variables** -> **Actions**。
3. 點擊 **New repository secret**，新增以下變數：

| Name | Value | 說明 |
|------|-------|------|
| `VITE_GOOGLE_APP_SCRIPT_URL` | `https://script.google.com/...` | 您的 Google Apps Script 網址 (必填) |

您可以選擇性新增變數 (Configuration Variables) 或 Secrets：
- `VITE_PASS_THRESHOLD` (預設 3)
- `VITE_QUESTION_COUNT` (預設 5)

### 2. 推送程式碼

將程式碼推送到 `main` 或 `master` 分支，GitHub Actions 就會自動開始建置。

```bash
git add .
git commit -m "Deploy to GitHub Pages"
git push origin main
```

### 3. 開啟 GitHub Pages

1. 建置完成後，由 GitHub Actions 自動建立 `gh-pages` 分支。
2. 前往 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下的 **Source** 選擇 `Deploy from a branch`。
4. **Branch** 選擇 `gh-pages` 並且資料夾選擇 `/ (root)`。
5. 按下 **Save**。

稍等片刻，您就可以透過 `https://<您的帳號>.github.io/<專案名稱>/` 玩遊戲了！

> [!TIP]
> **找不到 `gh-pages` 分支？**
> 請點擊 Repository 上方的 **Actions** 分頁，檢查 `Deploy to GitHub Pages` 這個 workflow 是否 **已經執行成功 (呈現綠色勾勾)**。
> - 如果是 **紅色叉叉**：點進去查看錯誤訊息，通常是因為 Secret 沒設定好。
> - 如果 **沒有任何紀錄**：代表您可能還沒將 `.github/workflows/deploy.yml` 推送到 GitHub，請執行步驟 2 的指令。
> - 如果顯示 **Permission denied**：請到 Settings -> Actions -> General -> Workflow permissions，勾選 **Read and write permissions**。
